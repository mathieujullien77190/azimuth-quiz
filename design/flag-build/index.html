DRAPEAU QUI SE CONSTRUIT

Le telephone au milieu de la table. Retrouve le bon papier avant les autres.

Le drapeau se construit couleur par couleur — pas dans l'ordre final.

16
papiers possibles

Idee : le drapeau ne se construit pas dans l'ordre final (bleu-blanc-rouge) mais par etapes qui font varier les proportions — d'abord 100% bleu, puis moitie bleu / moitie rouge, puis enfin le tiers-tiers-tiers. Sur la table, un tas de papiers representant des drapeaux candidats s'amenuise a chaque etape : ceux qui ne collent plus au motif affiche disparaissent. Le but n'est pas de "dire la France", mais de mettre la main sur LE papier qui correspond encore avant les autres joueurs.
